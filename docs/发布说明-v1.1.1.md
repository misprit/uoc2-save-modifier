# 发布说明 —— v1.1.1（2026-11-20）

作者：**烟柳边城 misprit**

给外部玩家的说明：**这是什么、能干什么、有什么限制、出了问题找谁**。

## 这是什么

《统一指挥 2》(Unity of Command II) 的**存档修改器**。
解包即用（自带 Python 运行时，不需要装任何东西、不需要联网）。

## 怎么用（三步）

1. 双击 **`统一指挥2存档修改器.exe`**（会开一个浏览器窗口，这就是界面）；
   不想双击 exe 就双击 `run_web.bat`（同一个界面，多一个黑窗口）；
2. 启动页那一行显示「✓ 游戏本体：…」——**没显示**就点「手动指定游戏目录」，
   选到游戏根目录（里面应该有 `_packages` 或 `lib\uoc2`）；
3. 列表里选存档打开。**没有存档？** 把 `.usg` 文件**拖进窗口**，
   或者点「打开其他位置」选文件 —— 导入的是**副本**，改动只作用在副本上。

## 能干什么

* 看战役进度（声望 / 分数，可直接改）；
* 改单位（经验、战力、**移动力 / 行动力**、工事等级、特种兵挂载与**压制**、
  **作战标记**、显示名）；
* 改总部（CP、补给卡车、兵库、技能分支与专精）；
* 改卡牌与商店（价格、库存、上下架、**改成免费 / 收费**）；
* 恢复上次会议的牌局；
* 改**战斗中的**战区资产（空袭次数、炮舰轰炸次数等）；
* **支持 mod** —— 游戏目录里的用户包与 Steam 创意工坊里的 mod 都会被读进来；
* 界面语言**中 / 英**，默认跟随游戏设置，右上角可以随时改；
* 「战役」页是**只读**的：看战役位置、路线图、可选场景、场景名册、会议商店。

## 这一版（v1.1.0）比 v1.0.0 多了什么

* **启动器 exe**（不用找 bat 了）+ 全局作者署名；
* 单位页新增**移动力 / 行动力 / 工事等级**、**特种兵压制 / 恢复**、
  **作战标记**（不能撤退 / 后卫部队 / 反击）；
* 卡牌**改成免费 / 收费**点一下就看得见，状态单独一行；
* **英文界面**：补齐漏翻、修掉「打不开存档」的卡顿（显示层翻译拖慢热路径）；
* **写入安全**：删掉两个会写坏存档的入口（见下）、兵库延迟必须非负、
  兵力上限提示不再误报；
* 战役页**长列表限高 + 框内滚动**，不用拉一长条；
* **修了一个 bug**：作战标记（死守 / 后卫部队 / 反击）**三个互斥**，
  一个单位只能同时有一个 —— 原来能挂上两个，界面两个都亮着、游戏里却只生效一个（游戏自己从来不会产生这种状态）；
  现在点新的会**替换**旧的，写盘前核心库也会拦；
* 单位列表选中不再跳回顶部、Alt+滚轮方向跟活跃兵力一致。

## 安全承诺

* 每一次写回**先自动备份**（`_BACKUP.usg`），并可**一键撤销**上一次写回；
* 写回前弹**二次确认**，写盘是**原子替换**（中途断电不会写坏存档）；
* 撤销栈与游戏内的「重置会议」是两套机制 —— 你在游戏里手动改过同一个存档时，
  撤销会**拒绝执行并说明原因**（不会硬改），这时可以把 `_BACKUP.usg` 复制回去；
* **对游戏安装目录只读**，所有写入都在 `%LOCALAPPDATA%\.uoc2\save`；
* **宁可不给，也不给错**：把握不准的字段（比如总部经验 —— 游戏每次战役推进
  都会按战役规模重算，手写进去必然被覆盖）直接**不提供改法**，而不是让你改出一个
  会被游戏悄悄覆盖的值。

## 已知限制

1. **`.patch.yml` 增量不支持** —— mod 用 `foo.patch.yml` 替代 `foo.yml` 时，
   修改器读到的仍是原版文件；
2. **创意工坊 mod 里新增的战役 / 场景**暂时进不了「战役」页；
3. **Windows + Edge only**（游戏本身就是 Steam Windows 版）；
4. 改存档前请**先退出游戏** —— 文件被占用时写回会失败；
5. **总部经验 / 经验目标不能手改** —— 游戏按战役规模动态重算（见「安全承诺」）。

## 出问题了怎么反馈

* 日志在 `%LOCALAPPDATA%\.uoc2\modifier.log`
  （启动信息 + 每个请求 + 出错时的堆栈，**token 已打码**，可以直接贴）；
* 概览页「关于这个修改器」面板里写着**版本号**与这个日志路径 —— 反馈时带上版本号；
* 另存为的副本（`_BACKUP.usg`）也一并保留，便于对比出问题时存档长什么样。
