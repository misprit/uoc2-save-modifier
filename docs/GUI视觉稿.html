3 · 特种兵挂载规则（已并入单位页）

特种兵页已取消 —— 挂载 / 卸下是「某个单位的事」，跟单位放在一起才对。 这一段不再是功能页，只把游戏自己的挂载规矩写清楚（GUI 的备选区要照它过滤）。

游戏的判定（字节码 unit.pyc::UnitState._can_add_specialist_no_len）：
  1. 阵营必须相同 —— 单位的 type.faction = 特种兵的 faction；
  2. 国籍必须相同；或者单位的国籍有「父国籍」且父国籍 = 特种兵的国籍 （例：italian.parent_nationality = german ⇒ 德军单位可挂意大利特种兵）；
  3. captured=True（被俘获的牌）跳过上面两条。
容量另算：len(specs) < max_spec， 而 max_spec = min(3, 类型表的 max_spec)（实测分布：1×233 / 2×314 / 3×80）。

过滤后，每个单位能挂多少种（实测真实存档 + 游戏包）

单位类型 阵营 / 国籍 可挂种数 备选区默认显示

特殊类型（flags）的中文名游戏自带 —— locale 键 id_sheet_spec_flag_*： at 反坦克炮 arty 火炮 towed 牵引式 engineers 工程兵 recon 侦察 ski 雪橇 lci 两栖 special 特种

手牌 · 4 / 上限 4 cards.yml

手牌 = 你已经拿到的牌（is_free=True）。 移除按位置，不是按类型。
ⓘ 手牌上的 is_free 没有玩法影响 —— 只改 tooltip 文案 （免费卡 / 已付费）与卡背贴图（face_down_free / face_down）。

卡牌商店货架 · 5 格 main.yml · card_store

ⓘ 购买扣声望（不是 CP）；is_free=True 的免费送 ⇒ 改免费就是白嫖，改收费按卡牌 cost 扣。 ⓘ 加载时不会重掷，但进入新会议会按权重重掷 —— 改了只管这一场。
ⓘ 换牌 / 上架只能选白名单里的卡（本存档本会议本来就能抽到的那 13 种）—— 登陆 / 空降卡会召唤单位，本战役没有登记的一律屏蔽。

卡牌图鉴 · 39 种 只读

贴图文件名 ≠ image 字段 ⇒ 查找顺序 bgt_ → bgmf_ → bgm_ → logo_ → 原名 → 去掉阵营后缀再试 → 用类型名兜底 → 占位（实测 39/39 全部命中）。
ⓘ 灰色 = 本战役商店不会抽到（换牌 / 上架时不可选），悬停看原因。屏蔽有三种： ① 阵营不是玩家阵营（本存档玩家 = axis，所以 26 张盟军 / 苏联牌全灰）； ② 本次会议权重被覆盖成 0（如 naval_bombardment）； ③ 登陆 / 空降卡本战役没有可召唤的单位。

ⓘ 所以只允许换成商店本来就能生成的卡，核心库写盘前还会再校验一遍。
