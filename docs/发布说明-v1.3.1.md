# 发布说明 —— v1.3.1（2026-11-26）

作者：**烟柳边城 misprit**

给外部玩家的说明：**这是什么、能干什么、有什么限制、出了问题找谁**。

## 这是什么

《统一指挥 2》(Unity of Command II) 的**存档修改器**。
解包即用（自带 Python 运行时，不需要装任何东西、不需要联网）。

## 怎么用（三步）

1. 双击 **`统一指挥2存档修改器.exe`**（会开一个浏览器窗口，这就是界面）；
   不想双击 exe 就双击 `run_web.bat`（同一个界面，多一个黑窗口）；
2. 启动页那一行显示「✓ 游戏本体：…」——**没显示**就点「手动指定游戏目录」，
   选到游戏根目录（里面应该有 `_packages` 或 `lib\uoc2`）；
3. 列表里选存档打开。**没有存档？** 把 `.usg` 文件**拖进窗口**，
   或者点「打开其他位置」选文件 —— 导入的是**副本**，改动只作用在副本上。

## 能干什么

* 看战役进度（声望 / 分数，可直接改）；
* 改单位（经验、战力、**移动力 / 行动力**、工事等级、特种兵挂载与**压制**、
  **作战标记**、显示名）；
* 改总部（CP、补给卡车、兵库、技能分支与专精）；
* 改卡牌与商店（价格、库存、上下架、**改成免费 / 收费**、**标记是否已使用**）；
* 恢复上次会议的牌局；
* 改**战斗中的**战区资产（空袭次数、炮舰轰炸次数等）；
* **修复被摧毁的城市（废墟）** —— 战役页「废墟」块，一键把打废的城市修回完好；
* **备份可以批量回收** —— 概览页「管理备份」里勾选、看清名单再确认；
* **支持 mod** —— 游戏目录里的用户包与 Steam 创意工坊里的 mod 都会被读进来；
* 界面语言**中 / 英**，默认跟随游戏设置，右上角可以随时改。

## 这一版（v1.3.1）修了什么

这一版主要是**修 bug**：把社区测试反馈里的 16 个真问题逐条定位并修掉。
下面按「你可能会遇到的样子」分组：

### 商店与兵库

* **删掉一个商品再把同一个加回来，现在能加上了**（以前一律被「重复条目」拦下，
  整批改动都提交不了）。
* **商店里所有商品下架之后，仍然能继续上架新商品**（以前会误显示
  「这个存档没有商店数据」）。
* **兵库里「新增兵力」的国籍 / 兵种下拉能选了**（以前选完还是显示 `this value`）。
* **兵库整个清空之后，仍然有「加条目」按钮**。
* **数量现在可以直接输入**（商店库存、总部兵库数量 —— 以前只能用滚轮加减，
  滚轮还留着）。

### 总部与改名

* **调整总部等级之后，界面会跟着更新**（以前显示升级了，再调压制却按旧等级算）。
* **改名会同步到全部 4 份副本**（战役地图点选场景时看到的「出场指挥部」名，
  现在也跟着变）。

### 卡牌

* **同一张卡不能重复上架到货架**（以前能加两次，地图上会出现两个同款兵模，
  先摆的那个点不动）。
* **存档里没有手牌文件时，手牌页会明确说明**（以前能挑卡、看着挑好了，
  到「应用更改」才被拦下）。

### 切换与重读

* **切换到别的存档之后，战役页（路线图 / 废墟 / 场景名册）不再串数据**。
* **「重新读取」现在真的会丢弃没应用的改动**。

### 数值与文案

* **单位经验上限按游戏的实际逻辑改成 399**（游戏的结算代码写死了 399，
  填 400 会被读档时拉回去）。
* **移动力有了上限**（不能填超出该单位类型的值）。
* 行动力、移动力、「可用数目」几处说明改成了直白话。

### 新增：持续卡可以标记「是否已使用」

**持续卡**（伞兵、师级空降、间谍、破坏、补给卡车这类 —— 用过一次之后
仍然留在牌堆里的卡）现在可以在手牌页直接切换「已使用 / 未使用」。

> 非持续卡用完就会从战役里移除，标不标没有意义，所以不给这个开关。

### 新增：备份可以批量回收

概览页「管理备份」里可以勾选备份、看清楚要回收的完整名单与总大小、确认后逐份处理。
处理过程中遇到问题会停下，并分别报告「已回收 / 未确认成功 / 未尝试」。

> 只处理程序自己 `bak` 目录里、能核对归属的备份；**不提供一键清空**。

### 新增：程序数据不再散落

设置、日志、导入副本、缓存、撤销记录都收进程序目录的 `data\` 下，
备份仍在 `bak\`。**旧的数据只兼容读取，不会自动搬走或删除。**

## 已知限制

* **手牌里不能直接加空降 / 登陆卡** —— 这是保守兜底，崩溃的根因还没定位，
  所以整类先禁用；卡牌商店那一侧另外做了同类型去重。
* **场景变体、技能图标变体**还不能改（只读展示）。
* **战役页除废墟修复外都是只读的**。
* 修改器只写存档的**根层几张表**，游戏自己的历史战报、战役名册等一律不动。

## 出了问题找谁

* 有 bug：把**复现步骤**和**存档文件**发到发布页的讨论区；
* 存档打不开：**先从 `bak\` 里恢复备份**（每次写盘前修改器都会先备份一份），
  再把情况发出来。

## 升级说明

直接解压新包覆盖即可。**旧版本的数据不用手动搬**，新版本会照旧读它们
（只读兼容，不会删你的东西）。
