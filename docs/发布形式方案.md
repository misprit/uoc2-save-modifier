# 发布形式方案（未来当 Steam Mod 分发）

> **【2026-11-19 · 用户提问】**
> 「封装这块我没有经验……我倾向于最好是一个 exe 打开即用。我未来会把产物作为
> Steam 的 mod 上传并且分发……这个 Mod 本身不能支持运行你这个应用，
> Steam 只做一个下载的工具。」
>
> ⇒ 目标形态：**Steam 创意工坊里放一个「下载包」，用户点一下就能用**。

## 现状（实测，不是估的）

| 项 | 数字 |
|---|---|
| 成品 zip | **12.7 MB**（303 个文件） |
| 解压后 | **26.8 MB**（python/ 22.6 + src/ 1.4 + docs/ 1.7 + tests/ 1.0） |
| 界面 | Web 版：本地 HTTP（只听 127.0.0.1 + 随机 token）+ Edge `--app` 窗口 |
| 依赖 | Edge（Windows 10/11 自带）；**界面是纯 HTML ⇒ 任何浏览器都能用** |
| 存档 / 配置位置 | `%LOCALAPPDATA%\.uoc2\` ⇒ **不在创意工坊文件夹里**，Steam 更新不影响它 |

> U78 刚砍掉 Tcl/Tk（无浏览器兼容层）：35.3 MB → **26.8 MB**（zip 16 → 12.7 MB）。
> 界面既然是纯 HTML，**没有 Edge 时用默认浏览器打开就行** ⇒ 不需要 Tk 那一层。

## 四种形式

### 方案 1 —— zip 解压即用（现状）

| | |
|---|---|
| 交付物 | 1 个 zip（**12.7 MB**） |
| 用户动作 | 解压 → 双击 `run_web.bat` |
| 优点 | 零构建；文件透明好改；Defender 基本不拦；现在就能发 |
| 缺点 | **不是「一个 exe」**；文件夹 300 个文件看着乱；**创意工坊里体验差**（订阅完还要自己解压） |
| Steam 适配 | ★☆☆☆ |

### 方案 2 —— 整个目录进创意工坊 + 一个 30 KB 启动器 exe ★推荐

| | |
|---|---|
| 交付物 | 创意工坊文件夹 = **26.8 MB**（含一个 ~30 KB 的 `统一指挥2存档修改器.exe`） |
| 用户动作 | Steam 订阅 → 打开创意工坊文件夹 → **双击那一个 exe** |
| 优点 | 用户只点一样东西（符合「傻瓜」定位）；**启动快**（不用每次解包）；**Steam 下载不带 MOTW ⇒ 没有 SmartScreen 弹窗**；**更新 = 改文件 → Steam 自动同步**；启动器可**回退到默认浏览器**（没有 Edge 也能用） |
| 缺点 | 仍然是「一个文件夹」（用户不用管而已）；exe **无签名** ⇒ Defender 启发式**可能**误报（典型形态就是「小 exe 去拉起 python」）⇒ 备选：启动器先开一个黑窗口（顺便给用户看日志），或同时留一个 `.bat` |
| 启动器怎么来 | **.NET Framework 4 自带的 `csc.exe` 本机就有**（`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`）⇒ 写个 200 行 C#，编译出 **20–40 KB** 的 exe，**零第三方工具链** |
| Steam 适配 | ★★★★☆ |

### 方案 3 —— PyInstaller 单文件 exe

| | |
|---|---|
| 交付物 | 1 个 exe，**约 15–22 MB**（⚠️ **估算，本机没装 PyInstaller，没实测**） |
| 优点 | 真的「一个文件」，扔哪都能跑 |
| 缺点 | **每次启动解包到 `%TEMP%`**（慢 1–3 秒）；Defender 对未签名 onefile **更容易**告警；更新要重发整个 exe；**词表与页面被打进 exe** ⇒ 改一句文案要重新打包；每次启动被杀软扫一遍 |
| Steam 适配 | ★★★☆☆ |

### 方案 4 —— 原生 exe（WebView2 / Tauri / .NET WebView2）

| | |
|---|---|
| 交付物 | **5–10 MB**（用系统自带 WebView2，不带浏览器内核） |
| 优点 | 最小、最快、最像正经软件 |
| 缺点 | **核心库是 Python** ⇒ 要么把整个核心重写成 JS/Rust（工作量以「月」计，667 个测试一起重写），要么 exe 只是壳、仍要带 Python ⇒ **体积没省 ⇒ 不划算** |
| Steam 适配 | ★★★☆☆（工作量巨大） |

## 建议：方案 2

1. 用户体验就是「点一个 exe」；
2. **更新免费**（Steam 按文件 diff 同步）⇒ U75 做的版本号 + 日志正好配套；
3. 不引入 PyInstaller 那种「每次启动解包 + 杀软高危」的形态；
4. 启动器用系统自带 `csc.exe` 编译，**不引入任何第三方工具链**；
5. 启动器顺手解决「没有 Edge」⇒ 回退到默认浏览器（界面本来就是纯 HTML）。

## Steam 侧要注意的

* 创意工坊 item 需要 标题 / 描述 / **预览图**（界面截图即可）；
* 文件落在 `<steam>/steamapps/workshop/content/809230/<itemid>/`；
  用户的存档与设置在 `%LOCALAPPDATA%\.uoc2\` ⇒ **Steam 覆盖更新不会丢**；
* Steam 更新是**按文件 diff** ⇒ 只改几个文件时，订阅端下载量很小；
* ⚠️ UoC2 的游戏本体**不会**去读创意工坊目录（`paths.pyc` 实证：标准启动不加载创意工坊包）
  ⇒ 我们把 exe 放在那里**不影响游戏**；
* ⚠️ 「工具类」内容能否正常出现在 UoC2 的创意工坊里，**Steam 侧不保证**
  ⇒ 建议**同时**准备一个网盘/网页备用下载链接，写在创意工坊描述里。
