# 发布说明 —— v1.4.2（2026-11-28）

作者：**烟柳边城 misprit**

给外部玩家的说明：**这是什么、能干什么、有什么限制、出了问题找谁**。

## 这是什么

《统一指挥 2》(Unity of Command II) 的**存档修改器**。
解包即用（自带 Python 运行时，不需要装任何东西、不需要联网）。

## 怎么用（三步）

1. 双击 **`统一指挥2存档修改器.exe`**（会开一个浏览器窗口，这就是界面）；
   不想双击 exe 就双击 `run_web.bat`（同一个界面，多一个黑窗口）；
2. 启动页那一行显示「✓ 游戏本体：…」——**没显示**就点「手动指定游戏目录」，
   选到游戏根目录（里面应该有 `_packages` 或 `lib\uoc2`）；
3. 列表里选存档打开。**没有存档？** 把 `.usg` 文件**拖进窗口**，
   或者点「打开其他位置」选文件 —— 导入的是**副本**，改动只作用在副本上。

## 能干什么

* 看战役进度（声望 / 分数，可直接改）；
* 改单位（经验、战力、**移动力 / 行动力**、工事等级、特种兵挂载与**压制**、
  **作战标记**、显示名）；
* 改总部（CP、补给卡车、兵库、技能分支与专精）；
* 改卡牌与商店（价格、库存、上下架、**改成免费 / 收费**、**标记是否已使用**）；
* 恢复上次会议的牌局；
* 改**战斗中的**战区资产（空袭次数、炮舰轰炸次数等）；
* **修复被摧毁的城市（废墟）** —— 战役页「废墟」块，一键把打废的城市修回完好；
* **备份可以批量回收** —— 概览页「管理备份」里勾选、看清名单再确认；
* **支持 mod** —— 游戏目录里的用户包与 Steam 创意工坊里的 mod 都会被读进来；
* 界面语言**中 / 英**，默认跟随游戏设置，右上角可以随时改。

## 这一版（v1.4.2）修了什么

**v1.4.2 是个修订版**：没有新功能，只修三个玩家实测报上来的问题。

### 修复一：第一次双击打不开 / 点「应用更改」报 “Failed to fetch”

* **症状**：解压后**第一次**双击 exe，窗口弹出但显示「无法访问此网站」；
  关掉再开第二次就正常了；有时改东西点「应用更改」会报 `Failed to fetch`。
* **原因**：程序把**浏览器启动进程退出**误当成「你把窗口关了」⇒
  顺手把后台服务关掉了 ⇒ 页面加载不出来、写回请求发不出去。
* **现在**：改成按「**界面还开着没有**」判断 ——
  界面每 15 秒给服务报个平安，关掉窗口时立刻通知服务，
  万一浏览器崩溃了，180 秒收不到平安信号才当作异常退出。
* **体感**：
  * 界面开着**什么都不干**（放一晚上也行）**不会自己退出**；
  * 关掉窗口后十几秒内，服务安静退掉，不留后台进程。

### 修复二：「管理备份」里一条备份都没有

* **症状**：概览页显示有备份，但进「管理备份」却一条都列不出来、也删不掉。
* **原因**：程序装在**存档目录里面**的时候，它自己的备份目录也落在存档目录里面，
  被一道安全闸门（“别把存档目录里的文件当成备份删掉”）**整个跳过**了。
* **现在**：程序**自己写的**备份目录不再被那道闸门误伤，列表和回收都正常。
* **安全边界没有变**：如果你把备份目录指到存档目录本身，
  那里面的东西**仍然一个都不会列、不会删**。

## 已知限制

* **手牌里不能直接加空降 / 登陆卡** —— 这是保守兜底，崩溃的根因还没定位，
  所以整类先禁用；卡牌商店那一侧另外做了同类型去重。
* **场景变体、技能图标变体**还不能改（只读展示）。
* **战役页除废墟修复外都是只读的**。
* 修改器只写存档的**根层几张表**，游戏自己的历史战报、战役名册等一律不动。
* **总部的经验与经验目标不能手改** —— 游戏按战役规模每次推进都重算，
  想给总部升级请直接改分支等级与技能专精。

## 出了问题找谁

* 有 bug：把**复现步骤**和**存档文件**发到发布页的讨论区；
* 存档打不开：**先从 `bak\` 里恢复备份**（每次写盘前修改器都会先备份一份），
  再把情况发出来。

## 升级说明

直接解压新包覆盖即可。**旧版本的数据不用手动搬**，新版本会照旧读它们
（只读兼容，不会删你的东西）。
