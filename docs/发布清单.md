# 发布清单（UOC2 存档修改器 v1.0.0）

> **口径（2026-11-19 用户拍板）**
> * **平台只做 Windows + Edge** —— 游戏只支持 Steam Windows，Windows 自带 Edge
>   ⇒ **不做跨平台、不做无浏览器兼容**；
> * **不做新手教程 / 向导** —— 使用者都是玩过游戏的人，界面已经足够傻瓜；
> * 目标：把包交给**外部玩家**，在**他自己的机器**上用。
>
> ⇒ 本文只列「发布前还要做的事」，功能开发不在此列。

## 已知限制（发布时一并说明）

1. **`.patch.yml` 增量不支持** —— mod 用 `foo.patch.yml` 替代 `foo.yml` 时，
   修改器读到的仍是原版文件（官方包 0 个用到，但 mod 可能用）；
2. **创意工坊 mod 新增的战役 / 场景进不了「战役」页** —— 那一页的清单是内置的；
3. **Windows + Edge only**（按口径不做别的）；
4. 修改器只写 `%LOCALAPPDATA%\.uoc2\save`，**对游戏安装目录只读**。
