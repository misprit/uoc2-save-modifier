## 已知限制（发布时一并说明）

1. **`.patch.yml` 增量不支持** —— mod 用 `foo.patch.yml` 替代 `foo.yml` 时，
   修改器读到的仍是原版文件（官方包 0 个用到，但 mod 可能用）；
2. **创意工坊 mod 新增的战役 / 场景进不了「战役」页** —— 那一页的清单是内置的；
3. **Windows + Edge only**（按口径不做别的）——
   成品包**不含**无浏览器兼容层（没有 Tk 备用简版），体积也因此小了一截；
4. 修改器写 `%LOCALAPPDATA%\.uoc2\save`（存档）与**修改器目录的 `bak` 文件夹**（自动备份），
   **对游戏安装目录只读**；
5. **总部经验 / 经验目标不能手改** —— 游戏按战役规模动态重算
   （U94 起；对外文档已写明，想升级请改分支等级 / 技能专精）。
