## 一句话结论

**v1.4.2 已定版**（2026-11-27）：
① 版本号升 **1.4.2**（**修订位 +1** ⇒ 只修 bug）；
② 发布形式 = **GitHub Release 公开**（v1.2.0 起）+ 自己分享压缩包。

**这一版修的是玩家实测报上来的两个故障**：
① 解压后**第一次**双击 exe ⇒ Edge 窗口显示「无法访问此网站」，第二次才正常；
② 点「应用更改」写回时报 "Failed to fetch"。

**根因**：启动器把「Edge 首个进程退出」误当成「用户关了窗口」⇒ **杀掉服务**
（实测：Edge 启动 `--app` 时被拉起的 pid 0.5 秒就退出，而窗口照常开着）。
⇒ 改成按**客户端在场信号**判活（心跳 + 关窗 beacon + 180 秒兜底）。

**另外**：启动页作者名下加了一行「特别鸣谢 IQ180 的学生会会计的详细测试」
（⚠️ **人名不翻译** ⇒ 英文界面也保留原样）。

**还有两处玩家实测报上来的**（打包后、发布前发现 ⇒ 版本号不变，仍是 v1.4.2）：
① **管理备份里一条都没有**（概览页却显示正常）——
   程序装在存档目录里时，`bak/` 落在存档目录**里面** ⇒
   管理备份那道闸把**程序专属**的备份目录也一起否了 ⇒ 一条都列不出来
   ⇒ 改成「程序专属的 `<修改器目录>/bak/` 豁免那道闸」，
   **安全边界不变**（`UOC2_BAK_DIR` 指到存档目录时仍然一个都不列）；
② **鸣谢里的人名被翻译了** ⇒ 拆成三段（可译 / **人名** / 可译），
   人名不进词表 + 进审计的 `NO_TRANS` 白名单 ⇒ 英文界面原样保留。
其余都验过了：下面逐项状态（✅ = 实测过 / ⬜ = 还差）。
① 版本号升 **1.3.0**（v1.2.0 之后 = **一个新功能**「修复废墟（被摧毁的城市）」

## 已知限制（发布时一并说明）

1. **`.patch.yml` 增量不支持** —— mod 用 `foo.patch.yml` 替代 `foo.yml` 时，
   修改器读到的仍是原版文件（官方包 0 个用到，但 mod 可能用）；
2. **创意工坊 mod 新增的战役 / 场景进不了「战役」页** —— 那一页的清单是内置的；
3. **Windows + Edge only**（按口径不做别的）——
   成品包**不含**无浏览器兼容层（没有 Tk 备用简版），体积也因此小了一截；
4. 修改器写 `%LOCALAPPDATA%\.uoc2\save`（存档）与**修改器目录的 `bak` 文件夹**（自动备份），
   **对游戏安装目录只读**；
5. **总部经验 / 经验目标不能手改** —— 游戏按战役规模动态重算
   （U94 起；对外文档已写明，想升级请改分支等级 / 技能专精）；
6. **手牌里不能直接加空降 / 登陆卡** —— 这是保守兜底（崩溃根因是「同一个单位
   被两个主体引用」，但游戏自己写出的存档里也有同样形态 ⇒ 离线无法定位触发条件）
   ⇒ 手牌侧整类禁用，卡牌商店侧不受影响；
7. **场景变体 / 技能图标变体不支持** —— 各 HQ 的技能树差异本来就是对的
   （数据取自存档里该总部的技能树），技能图标全游戏只有一套；
   「场景变体」是游戏包里的配置，存档侧收益小、风险大 ⇒ 不做。
