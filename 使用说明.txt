UOC2 存档修改器 —— 核心库 + 图形界面 + 自测入口
=================================================
作者：烟柳边城 misprit

这是一个《Unity of Command II》(统一指挥 2) 的存档修改核心库，
以及基于它的图形界面（GUI）和命令行自测入口。

    · 核心库  src\save_modifier_core\   —— 真正干活的部分，无界面，可被任何 GUI 直接 import
    · 图形界面 src\save_modifier_web\    —— ★ 正式界面（本地 HTTP + 浏览器窗口）
    · 自测入口 src\save_modifier\        —— 核心库的命令行外壳，供开发/排查用


一、怎么启动（Windows 10/11 64 位，不需要装 Python、不需要联网）
----------------------------------------------------------------
    ★ 图形界面：**双击 `统一指挥2存档修改器.exe`**
               —— 它会起一个本地服务（只监听 127.0.0.1，带随机 token），
                  并用 Edge 开一个独立窗口；关掉窗口服务就退出。
                  （没有 Edge 就用默认浏览器打开，功能一样。）
    等价写法：双击 run_web.bat（同一个界面，多一个黑窗口）
    命令行：  双击 run.bat
    跑测试：  双击 run_tests.bat
    只做自检（不进入交互）：
               run.bat --check
               run_web.bat --check
               （也可以直接双击那个 exe —— 界面本身就是界面层说明）


二、第一次用，先做这两件事
--------------------------
1) **告诉修改器游戏装在哪**
   界面启动页那一行会显示「✓ 游戏本体：…」；
   显示不出来（⚠ 没找到游戏本体目录）就点那一行的「手动指定游戏目录」，
   选到游戏根目录（里面应该有 _packages 或 lib\uoc2）。
   —— 特种兵 / 卡牌 / 战役名册 / 商店默认值 / 贴图都从这个目录读。

2) **确认存档在哪**
   存档用的是游戏自己的目录：%LOCALAPPDATA%\.uoc2\save\
   （campaigns\ = 战役存档，games\ = 独立场景存档）。
   列表里没有存档时：把 .usg 文件**拖进窗口**，或者点「打开其他位置」选文件
   —— 导入进来的是**副本**，改动只作用在副本上。


三、能做什么
------------
    - 列出并打开存档（战役存档与独立场景存档都支持）；
    - 查看战役进度：声望、分数（可直接改）；
    - 查看与修改单位：经验、战力、**移动力 / 行动力**、工事等级、
      特种兵（挂载 / 压制）、**作战标记**（不能撤退 / 后卫部队 / 反击）、显示名；
    - 查看与修改总部：CP、补给卡车、兵库、技能分支与专精；
      （总部经验与经验目标由游戏按战役规模**动态重算**，**不能手改** ——
        想升级请改**分支等级 / 技能专精**）
    - 查看与修改卡牌与商店（价格、库存、上下架、**改成免费 / 收费**）；
    - 恢复上次会议的牌局；
    - 查看战役位置、路线图、可选场景、场景名册与会议商店（**只读**）；
    - 修改当前战斗的战区资产（空袭次数、炮舰轰炸次数等）；
    - **支持 mod**：游戏目录里的用户包（%LOCALAPPDATA%\.uoc2\_packages\）
      与 Steam 创意工坊里的 mod 都会被读进来（磁盘上的包优先）；
    - 每一次写回都会自动备份，并可**一键撤销**上一次写回。


四、界面语言：中 / 英
---------------------
界面语言**默认跟随游戏设置**（游戏用英文就是英文）。
右上角有一枚「EN / 中文」按钮，可以随时改成
「跟随游戏 / 中文 / English」——这个选择只写修改器自己的设置，不碰存档。
切成英文后，界面、报错、单位/特种兵/卡牌/战役的名字都会一起变成英文
（名字取自游戏自己的英文资源）。


五、怎么用（命令行）
--------------------
    输入 help 看命令列表。各命令的参数见 docs\命令参考.md。

    典型流程：
        saves            列出存档
        open 1           打开第一个
        view             看概览
        xp 1 300         规划：把 1 号单位经验改成 300（此时还没写盘）
        plan             看 diff
        commit           确认写回（自动备份 + 可撤销）
        undo             不满意就撤


六、目录说明
------------
    python\   自带的 CPython 3.14.3 解释器与 PyYAML 6.0.3
    src\      程序本体
              save_modifier_core\   ★ 核心库（GUI 只要复制这个包）
              save_modifier_web\    ★ 正式界面（HTML/CSS + 本地 HTTP）
              save_modifier\        自测入口
    docs\     参考文档（核心库调用说明 / 命令参考 / 开发上下文 / GUI 设计规范 /
               英文支持可行性报告 / 发布清单 / 发布说明）
              ⚠️ docs\证据脚本\ 是**开发过程**的证据脚本，写死了本机路径，
                 只在开发机上跑得通 —— 外部使用者不用管。
    tests\    自动化测试（1082 项；标准库 unittest，不需要 pytest）
    统一指挥2存档修改器.exe  ★ 启动正式界面（推荐双击这个）
    run_web.bat       启动正式界面（等价，带黑窗口）
    run.bat           启动自测入口
    run_tests.bat     跑全部自动化测试


七、注意事项
------------
    - 适用于 Windows 10/11 64 位。
    - 请解压到有写权限的目录（例如 D:\UOC2工具），不要放在 Program Files 下。
    - 存档修改需在游戏内重新读档才生效。
    - 每次写回都会先备份：备份文件放在**修改器所在目录的 bak 文件夹**里
      （<存档名>_BACKUP.usg；同名已有则用 _BACKUP_2…，绝不覆盖）。
      存档目录里**不会**再留下备份 —— 游戏只扫存档目录里的 *.usg，
      备份放那儿会被游戏当成存档列出来（容易点错）。
    - 撤销栈仍是存档旁边的 <存档名>.undo.json（一个存档一个文件，
      游戏只读 *.usg，不会把它当存档）。
      **备份存档时，把 bak 文件夹和 .undo.json 一起带上。**
    - 撤销栈与游戏内的「重置会议」是两套独立机制：如果你在游戏里手动改过同一个存档，
      撤销会**拒绝执行并说明原因**（不会硬改），这时可以直接把 _BACKUP.usg 复制回去。
    - 脚本对游戏安装目录只读；存档的写入都在 %LOCALAPPDATA%\.uoc2\save 下，
      备份写到**修改器所在目录的 bak 文件夹**里 ⇒ 那个目录要有写权限。
    - 改存档前请**先退出游戏** —— 文件被占用时写回会失败。
    - 遇到问题要反馈？日志在 %LOCALAPPDATA%\.uoc2\modifier.log
      （启动信息 + 每个请求 + 出错时的堆栈；**token 已打码**，可以直接贴）。
      概览页**最底下**那一行写着版本号与这个日志路径。


八、已知限制
------------
    - mod 用 `<同名>.patch.yml` 替代 `<同名>.yml` 时（.patch.yml 增量机制），
      修改器读到的仍是原版文件 —— 暂不支持这种增量写法。
    - Steam 创意工坊 mod 里**新增的战役/场景**暂时进不了「战役」页
      （那一页的战役/场景清单是内置的）。
    - 随包测试在没有游戏/没有存档的机器上会自动跳过相关用例（不会失败）。
    - 这个包**只支持 Windows + Edge**（游戏本身就是 Steam Windows 版）。
