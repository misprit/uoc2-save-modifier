UOC2 存档修改器

这是一个运行在命令行中的《Unity of Command II》存档修改器，可编辑战役存档与
独立场景存档。启动后进入交互界面，逐条输入命令。

脚本能够实现的功能：

  - 打开与切换存档：列出全部主存档并标注其为战役存档或场景存档，也可按名称
    打开未出现在列表中的备份存档。
  - 保存与备份：把修改整体写回存档；为当前存档建立快捷备份、用该备份恢复；
    丢弃未保存的修改，重新从存档读取。
  - 修改声望与战区资产：设置声望（可直接指定，也可在当前值上增减）；设置空袭、
    空中补给、炮舰轰炸等战区资产在当前战斗中的可用次数。
  - 管理战役卡牌（仅战役存档）：查看持有的卡牌与槽位占用；添加卡牌、按费用
    购买、删除卡牌，把已使用的卡牌恢复为未使用。
  - 修改单位：按中文名、名称 id 或类型查找单位；修改经验、战力与类型；挂载或
    移除特种兵；也可直接改写单位的任意字段。
  - 自定义单位类型：以原版单位或特种为原型，在临时 mod 中克隆新类型（复制贴图，
    可另行指定模型来源）；把单位绑定到该类型、查看已有绑定，并在战役推进后
    重新套用绑定；也可重命名已创建的自定义实体。
  - 名称与中文文本：修改单个单位的显示名，或修改类型实体（单位、特种）的简称
    与全称；文本写入本存档独立的本地化文件，不影响其他存档。
  - 查阅参考资料：打开战役部队列表、战役总部列表、按阵营分组的卡牌列表、
    临时 mod 目录与原版包目录；显示当前存档、工作目录、临时 mod 与绑定文件的
    路径。
  - 不进交互界面的快捷存读档：把默认存档备份，或用该备份恢复，供 AHK 等热键
    工具调用（见第四节）。

各命令的参数、写法、生效方式与已知限制，详见 docs\命令参考.md。

一、怎么启动
    双击本目录下的 run.bat。
    不需要安装 Python，也不需要联网。

二、首次运行会引导配置
    会依次询问三项，每项直接回车即采用方括号中的默认值：
      1. 游戏数据目录（一般是 %LOCALAPPDATA%\.uoc2）
      2. 原版 _packages 目录（游戏安装目录下，例如 Steam 库里的游戏目录）
         用于读取单位/卡牌的中文名与卡牌费用，以及以原版为原型创建自定义类型。
         自动探测失败且不确定时可留空，但留空后：单位与总部只显示本地化 id，
         find 不能按中文名搜索，cardBuy 查不到费用，也不能创建新类型。
         改声望、战力、经验等数值不受影响。
      3. 本地化语言（默认 chi）
    初始配置来自 config\config.default.yml（带注释），首次运行会把它复制成
    config\config.yml 再就地确认上述几项。以后想改可直接编辑该文件，
    也可以运行 run.bat --setup 重新引导。

    存档解包工作区与参考列表默认放在本目录下的 data\；要放回游戏数据目录
    （%LOCALAPPDATA%\.uoc2\modifier）或自定义路径，改 config.yml 的 state_dir：
    留空 "" 为默认（本目录 data\），"appdata" 为游戏数据目录，其他为自定义路径。

    脚本对游戏包是只读的，用于获取中文本地化文件、解析卡牌定义等，不会进行任何修改。
    脚本对游戏数据的写入都在 %LOCALAPPDATA%\.uoc2 下，包括快捷存档、创建临时Mod
    以修改单位数据；解包工作区与参考列表则放在上面说的状态目录（默认本目录 data\）。

三、目录说明
    python\   自带的 Python 解释器与 PyYAML，约 25 MB
    src\      程序本体
    config\   配置（config.default.yml 模板；首次运行后才会多出 config.yml）
    data\     解包工作区与参考列表（首次打开存档后才会出现）
    docs\ note\  参考文档
    ！使用时请主要参考 docs\命令参考.md，详细讲述了各命令的用法和行为

四、给热键工具调用（不进交互界面）
    run.bat qs   把上次打开的存档备份为 <存档名>_quick.usg
    run.bat ql   用该备份恢复
    带参数调用时窗口不会暂停，按退出码判断成败：
      0 成功；1 配置问题；2 没有默认存档记录；
      3 默认存档不存在；4 没有备份；5 文件操作失败。
    
    脚本目前没有附带热键注册功能，该接口主要开放给AHK，用于游戏内一键quickSave/quickLoad

五、注意事项
    - 适用于 Windows 10/11 64 位。
    - 请解压到有写权限的目录（例如 D:\UOC2工具），
      不要放在 Program Files 下，否则首次生成配置会失败。
    - 存档修改需在游戏内重新读档生效；自定义单位需重启游戏。
