UOC2 存档修改器 —— 核心库 + 图形界面 + 自测入口
=================================================

这是一个《Unity of Command II》(统一指挥 2) 的存档修改核心库，
以及基于它的图形界面（GUI）和命令行自测入口。

    · 核心库  src\save_modifier_core\   —— 真正干活的部分，无界面，可被任何 GUI 直接 import
    · 图形界面 src\save_modifier_gui\   —— Tk 8.6 + ttk，原生窗口
    · 自测入口 src\save_modifier\        —— 核心库的命令行外壳，供开发/排查用

图形界面直接调用核心库的 8 个函数；本目录里的命令行入口只是开发时敲命令用的通道。
（运行时里已经带上了 Tcl/Tk 8.6，原生窗口开箱即用。）
图形界面正在本仓库内开发，设计稿见 docs\GUI设计规范.md 与 docs\GUI视觉稿.html。


一、怎么启动
    图形界面：双击本目录下的 run_gui.bat。
    命令行：  双击本目录下的 run.bat。
    不需要安装 Python，也不需要联网（python\ 里已经带了整套运行时）。

    只跑一遍自检（不进入交互）：
        run.bat --check
        run_gui.bat --check


二、能做什么
    - 列出并打开存档（战役存档与独立场景存档都支持）；
    - 查看战役进度：声望、分数；
    - 查看与修改单位：经验、战力、特种兵、显示名（直接写明文）；
    - 查看与修改总部：兵库存量；
    - 查看与修改卡牌与商店（价格、库存、下架）；
    - 恢复上次会议的牌局；
    - 修改当前战斗的战区资产（空袭次数、炮舰轰炸次数等）；
    - 每一次写回都会自动备份，并可**一键撤销**上一次写回。


三、怎么用（命令行）
    输入 help 看命令列表。各命令的参数见 docs\命令参考.md。

    典型流程：
        saves            列出存档
        open 1           打开第一个
        view             看概览
        units            看单位
        xp 1 300         规划：把 1 号单位经验改成 300（此时还没写盘）
        plan             看 diff
        commit           确认写回（自动备份 + 可撤销）
        undo             不满意就撤


四、给 GUI 开发者的说明
    核心库的接口、数据结构、能力位矩阵、错误处理约定，全在：
        docs\核心库调用说明.md

    8 个对外函数（接口已冻结，由 tests\test_api_contract.py 守着）：
        list_saves() / open_save() / save.view() / save.plan_edit() /
        validate() / save.commit() / save.undo() / catalog.*


五、目录说明
    python\   自带的 CPython 3.14.3 解释器与 PyYAML 6.0.3（约 31 MB，含 Tcl/Tk 8.6）
    lib\      Tcl/Tk 8.6 脚本库（GUI 层的运行时依赖）
    src\      程序本体
              save_modifier_core\   ★ 核心库（GUI 只要复制这个包）
              save_modifier_gui\    图形界面
              save_modifier\        自测入口
    docs\     参考文档（核心库调用说明 / 命令参考 / 开发上下文 / GUI 设计规范 / GUI 视觉稿）
    tests\    自动化测试（249 项）
    run_gui.bat       启动图形界面
    run.bat           启动自测入口
    run_tests.bat    跑全部自动化测试


六、注意事项
    - 适用于 Windows 10/11 64 位。
    - 请解压到有写权限的目录（例如 D:\UOC2工具），不要放在 Program Files 下。
    - 存档修改需在游戏内重新读档才生效。
    - 每次写回会在存档目录生成 <存档名>_BACKUP.usg（同名已有则用 _BACKUP_2…，
      绝不覆盖），并在旁边生成 <存档名>.undo.json（撤销栈）。
      **备份存档目录时把这两个文件一起带上。**
    - 撤销栈与游戏内的「重置会议」是两套独立机制：如果你在游戏里手动改过同一个存档，
      撤销会**拒绝执行并说明原因**（不会硬改），这时可以直接把 _BACKUP.usg 复制回去。
    - 脚本对游戏安装目录只读；所有写入都在 %LOCALAPPDATA%\.uoc2\save 下。
