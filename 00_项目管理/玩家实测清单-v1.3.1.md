## 〇、准备（5 分钟）

### 1. 造测试副本（**你的原档一个字节都不会动**）

```
.\python\python.exe tools\prepare_test_run.py
```

会在游戏存档目录里多出三个文件：`Stalingrad-test.usg`、`tester-cards-test.usg`、
`tester-overlord-test.usg`。它们是**副本**，测完用

```
.\python\python.exe tools\prepare_test_run.py --clean
```

删掉。游戏和修改器**都能**看到这三个存档（游戏只扫 `save\campaigns` 与 `save\games`）。

### 2. 起修改器（用仓库代码，不是旧包）

**双击 `run_web.bat`** —— 会自动开一个 Edge 窗口，那就是界面。

> 想用别的浏览器/窗口：`.\python\python.exe -m save_modifier_web.server --serve --no-window --no-browser`
> 然后手动打开它打印的那个 `http://127.0.0.1:<端口>/?t=<token>` 地址（**必须带 `?t=`**）。

### 3. 打开测试副本

在启动页的存档列表里选 **`Stalingrad-test.usg`**（战役进行中，单位多，什么都能测）。

> ⚠️ **别选没有 `-test` 后缀的** —— 那是你的原档。

### 4. 通用习惯

* 每次改完点「应用更改」之前，先看一眼底栏的待应用条数；
* 改坏了不要紧：修改器**每次写盘前都会把原档备份到程序目录的 `bak\`**，
  撤销栈也在（概览页「管理备份」里能看到备份列表）；
* **游戏开着的时候不要改盘** —— 游戏退出时会把内存里的存档写回去，把你的改动覆盖掉。

## 一、本轮**新功能**（必测，各 5 分钟）

### ⭐ T5 · 持续卡的「是否已使用」（N-5 新增）

**前置**：手牌里要有一张**持续卡**。持续卡 = 用过一次之后**仍然留在牌堆**里的卡
（伞兵、师级空降、间谍、破坏、补给卡车这类）。非持续卡（普通技能卡）**不该出现**这个开关。

| 步 | 操作 | 期望 |
|---|---|---|
| 1 | 进「卡牌」页，看手牌 | 持续卡上多了一行 **「未使用」**（灰色可点）；普通卡**没有**这一行 |
| 2 | 点一下那一行 | 变成 **「已使用」**（绿色），底栏多一条待应用 |
| 3 | 点「应用更改」 | 提示写入成功 |
| 4 | 进游戏读档，看这张卡 | 卡的**卡背/状态**按「已使用」显示 |
| 5 | 回修改器把它切回「未使用」→ 应用 → 读档 | 恢复原状 |

**算失败**：普通卡也出现这行 / 持续卡没出现 / 点了报「不是 persistent 卡型」/ 应用后游戏里没变化。

### ⭐ T9 · 数量可以直接键入（B1 新增）

| 步 | 操作 | 期望 |
|---|---|---|
| 1 | 进「商店」页，找一条有库存的商品 | **库存那一格现在是输入框**（不是滚轮），里面是当前库存 |
| 2 | 点进去，把 **1** 改成 **12** | 能打进去**两位数**；底栏出现「商店 … 库存 1 → 12」 |
| 3 | **不要点别处**，直接改成 **123** | 第二个字、第三个字**都能打进去**（这是关键：以前会被重绘打断） |
| 4 | 在输入框上**滚一下鼠标滚轮** | 数字 **±1**（滚轮没被拿掉） |
| 5 | 填 **0** | 输入框**变红并提示不能小于 1**（游戏没有「售罄」标记，0 不合法） |
| 6 | 进「总部」页 → 选一个总部 → 兵库 | 兵库每条右边的**数量也是输入框**；同样能键入、能滚轮 |
| 7 | 改完点「应用更改」 | 提示写入成功 |

**算失败**：只能改一位数 / 滚轮没了 / 填 0 被悄悄改成 1 而不是报错 / 兵库那格还是滚轮。

## 三、需求侧两条（R-1 / R-2）

### T16 · 备份批量回收（R-1）

1. 概览页 → **「管理备份」**；
2. 勾选要回收的备份 → 应该显示**完整名单 + 份数 + 总大小**；
3. 确认 → 逐份处理，过程中**遇到问题会停下**；
4. 结果分三档显示：**已回收 / 未确认成功 / 未尝试**；
5. **去 Windows 回收站把那份备份还原**（回收走的是回收站，不是永久删除）。

**算失败**：默认就全选了 / 有一键清空 / 结果只笼统说「失败」/ 回收站里找不到。

> 只处理程序 `bak\` 目录里**能核对归属**的备份；旧位置的备份只列出、不给回收权限。

### T17 · 便携布局（R-2）

1. 双击**新编译**的 `build\统一指挥2存档修改器.exe`（还没重新编译的话，先跑
   `tools\build_launcher.py`）；
2. 用它启动 → 设置 / 日志 / 导入副本 / 缓存 / 撤销记录都落在**程序目录的 `data\`**；
3. **备份仍在 `bak\`**；
4. 你原来 `%LOCALAPPDATA%\.uoc2` 里的旧数据**还在**（不会被自动搬走或删除）。
