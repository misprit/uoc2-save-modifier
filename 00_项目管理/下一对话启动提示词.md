## 本轮踩到的坑（**先看交接单 §三 的完整版**，这里是最容易再踩的）

1. **git 远端操作必须绕过代理**：全局 `http.proxy` → `127.0.0.1:7993` 而**代理软件没开**
   ⇒ `git -c http.proxy= -c https.proxy= push`（**不动全局配置**）。
2. **DNS 对 `github.com` 轮换返回多个真实 IP，且可达性随时间翻转**
   ⇒ 「记一个可用 IP」不成立：先 `curl.exe --resolve github.com:443:<IP> -o NUL -w "%{http_code}" https://github.com/`
   探到 200，**立刻**用 `git -c http.curloptResolve=github.com:443:<IP> push`；失败就换 IP / 隔 15–20 秒重来。
   ⚠️ **别用 git 的失败反推 IP 不可用**。
3. **中文 Markdown 的 `**粗体**` 会静默失效**（收尾 `**` 前是标点、后是汉字 ⇒ 不解析）
   ⇒ 要验就用 GitHub 的 `POST /markdown` 渲染端点（纯渲染、无副作用）。
4. **发布正文要独立复核** —— `release_publish.py` 只验资产字节，**不验正文渲染**。
5. **游戏目录被临时改动 ⇒ 干净环境测试红 4 条**（计数 +1）—— 排查看**目录** mtime，不是文件 mtime。
6. **搬 L2 整页模板里的块 ⇒ i18n 词表（键 + 值）都要同步**，否则英文界面不动。
7. **静态断言 + 真点巡检要对称，且必须实测能红**；反证要**精确到目标维度**。
8. **`git commit -m` 带反引号会被 PowerShell 吃掉** ⇒ 写到文件再 `git commit -F <文件>`。
9. **`rm --` 必须单独一条命令、只含字面量目标**；`Remove-Item` 被安全策略拒。
