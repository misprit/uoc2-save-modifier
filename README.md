# UOC2 存档修改器

《**统一指挥 2**》(Unity of Command II) 的存档修改器 —— 读存档、改存档、写回，**全程可撤销**。

作者：**烟柳边城 misprit** ｜ 平台：**Windows + Edge**（游戏本身就是 Steam Windows 版）

---

## 它能干什么

| 页 | 能改什么 |
|---|---|
| **概览** | 声望、分数、难度（改难度会连带手牌上限，改前先删手牌） |
| **单位** | 经验、战力、移动力 / 行动力、工事等级、特种兵挂载与压制、**作战标记**（不能撤退 / 后卫部队 / 反击）、显示名 |
| **总部** | CP、补给卡车、兵库、技能分支与专精 |
| **卡牌** | 手牌与货架：价格、库存、上下架、**改成免费 / 收费** |
| **商店** | 会议商店的货品、价格与库存 |
| **战区资产** | 战斗中能用的空袭 / 炮舰轰炸等次数 |
| **战役**（只读） | 战役位置、路线图、会议可选场景、场景名册、会议商店 |

另外：**支持 mod** —— 游戏目录里的用户包与 Steam 创意工坊里的 mod 都会被读进来；
界面语言**中 / 英**，默认跟随游戏设置。

## 快速开始

1. **解压**到一个有写权限的目录（例如 `D:\UOC2工具`，**不要放 Program Files**）；
2. 双击 **`统一指挥2存档修改器.exe`**（没有 exe 就双击 `run_web.bat`，同一个界面）；
3. 启动页会显示「✓ 游戏本体：…」—— 没显示就点那一行的「**手动指定游戏目录**」，
   选到游戏根目录（里面应该有 `_packages` 或 `lib\uoc2`）；
4. 列表里选存档打开。**列表里没有存档？** 把 `.usg` 文件**拖进窗口**，
   或者点「打开其他位置」选文件 —— 导入的是**副本**，改动只作用在副本上。

> 存档在游戏自己的目录：`%LOCALAPPDATA%\.uoc2\save\`（`campaigns\` = 战役存档，
> `games\` = 独立场景存档）。修改器**只写这个目录**（外加**修改器目录下的 `bak` 文件夹**
> —— 自动备份放那儿），对游戏安装目录**只读**。

## 安全承诺

- 每一次写回**先自动备份**（放在**修改器所在目录的 `bak` 文件夹**里：`bak\<存档名>_BACKUP.usg`），
  并可**一键撤销**上一次写回 —— 备份**不放存档旁边**，免得被游戏当成存档列出来；
- 写回前弹**二次确认**（列出逐条改动明细），写盘是**原子替换** —— 中途断电不会写坏存档；
- 撤销栈与游戏内的「重置会议」是两套机制：你在游戏里手动改过同一个存档时，
  撤销会**拒绝执行并说明原因**（不会硬改），这时把 `bak` 里的 `_BACKUP.usg` 复制回去即可；
- **凡是能写进存档的字段，核心库都硬校验** —— 超范围、类型不对、
  写出来游戏读不了的，直接报错拒绝写入，而不是让你改出一个坏存档；
- **把握不准的功能宁可不给**（例：总部经验与经验目标由游戏按战役规模动态重算，
  手写进去必被覆盖 ⇒ 不提供改法）。

```powershell
# 跑全部测试（1185 项，2026-11-23 实测）

#             真实存档写回 + 撤销演练 / 干净环境随包测试不红）
```

## 已知限制

1. **`.patch.yml` 增量不支持** —— mod 用 `foo.patch.yml` 替代 `foo.yml` 时，
   修改器读到的仍是原版文件；
2. **创意工坊 mod 里新增的战役 / 场景**暂时进不了「战役」页；
3. **Windows + Edge only**；
4. 改存档前请**先退出游戏** —— 文件被占用时写回会失败；
5. **总部经验 / 经验目标不能手改** —— 游戏按战役规模动态重算；
6. **备份在修改器目录的 `bak` 文件夹**里 —— 换机器 / 重装前记得把它一起带走
   （连同存档旁边的 `<存档名>.undo.json`）。
